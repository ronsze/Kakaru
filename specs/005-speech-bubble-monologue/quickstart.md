# Quickstart: 말풍선과 혼잣말 검증

## 자동 검증

```bash
npm test                                 # dialogue(정리·선택), speaker(일정·억제), lines 읽기
npx tsc -p tsconfig.node.json && npx tsc -p tsconfig.web.json
npm run test:e2e                         # 잡으면 "잡혔을 때" 말풍선이 나타나고 놓은 뒤 사라진다
```

E2E는 `KAKARU_USER_DATA`로 격리하며, 혼잣말 간격(20~40초)은 단위 테스트에서 시계를 주입해 확인한다.

## 수동 검증 (사람이 수행, `tests/manual/results.md`에 기록)

`npm run dev` 후:

1. 1분 안에 기본 캐릭터가 말풍선으로 혼잣말을 한다 (US1, SC-001).
2. 말풍선이 몇 초 뒤 사라지고, 걷는 동안 머리 위를 따라다닌다 (SC-002, 003).
3. 같은 말이 연속으로 반복되지 않는다 (US1-5).
4. 화면 네 가장자리 근처에서 말풍선이 잘리지 않는다 (SC-004). 위쪽 가장자리에서는 캐릭터 아래에 나온다.
5. 확대(3배)·축소(0.5배) 상태에서도 말풍선이 머리 위에 맞는다 (edge).
6. 말풍선 위치를 클릭해 아래 창이 정상 반응한다 (SC-005).
7. 설정 창에서 "빨간 모자"로 바꾸면 다른 문장이 나온다. 직접 등록한 캐릭터는 말하지 않는다 (US2, SC-006).
8. 캐릭터를 잡으면 "잡혔을 때", 5초 넘게 잡으면 "오래 잡혔을 때" 문장이 나오고, 기존 말풍선은 교체된다 (US3).
9. 우클릭 메뉴가 열려 있는 동안은 새 혼잣말이 나오지 않는다 (US3-4).
10. 모니터가 둘이면 캐릭터가 넘어가도 말풍선이 따라온다.
11. 10분 이상 켜 두고 유휴 CPU가 기준(평균 10% 이하) 안인지 본다 (SC-007).

macOS에서만 수행한다. Windows 열은 "후속".
