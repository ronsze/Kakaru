# Feature Specification: 메뉴의 종료·확대·축소

**Feature Branch**: `003-menu-quit-zoom`

**Created**: 2026-10-22

**Status**: Implemented (수치는 써 보면서 조정)

**Input**: User description: "종료 메뉴 항목 바로 추가, 확대·축소 메뉴도 각각 추가(캐릭터를 확대·축소하는 기능). 한 번에 얼마나 변하고 최대/최소값은 어떻게 할지는 해보면서 정리"

이 기능은 우클릭 메뉴(002)에 항목을 더하는 작은 변경이라 plan·tasks 없이 바로 구현했다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 메뉴에서 앱을 종료한다 (Priority: P1)

Dock과 메뉴 막대에 앱이 보이지 않으므로, 사용자가 캐릭터를 우클릭해 나오는 메뉴의 "종료"로 앱을 끝낸다.

**Independent Test**: 캐릭터를 우클릭해 "종료"를 선택하면 캐릭터가 사라지고 앱이 완전히 종료된다.

**Acceptance Scenarios**:

1. **Given** 앱이 실행 중일 때, **When** 메뉴에서 "종료"를 선택하면, **Then** 모든 캐릭터 창과 설정 창이 닫히고 앱 프로세스가 끝난다.
2. **Given** 설정 창이 열려 있을 때, **When** "종료"를 선택하면, **Then** 설정 창도 함께 닫힌다.

---

### User Story 2 - 캐릭터를 확대·축소한다 (Priority: P2)

사용자가 메뉴의 "확대"·"축소"로 캐릭터 크기를 한 단계씩 바꾼다. 바뀐 크기는 앱을 다시 실행해도 유지된다. 더 확대·축소할 수 없는 한계에서는 해당 메뉴 항목이 비활성화된다.

**Independent Test**: "확대"를 여러 번 선택하면 캐릭터가 점점 커지다가 최대에서 멈추고 "확대"가 비활성화된다. "축소"도 최소에서 같다. 앱을 다시 실행하면 마지막 크기로 나타난다.

**Acceptance Scenarios**:

1. **Given** 기본 크기일 때, **When** "확대"를 선택하면, **Then** 캐릭터가 한 단계만큼 커지고 위치·방향·이동 상태는 유지된다.
2. **Given** 기본 크기일 때, **When** "축소"를 선택하면, **Then** 캐릭터가 한 단계만큼 작아진다.
3. **Given** 최대 크기일 때, **When** 메뉴를 열면, **Then** "확대"는 비활성화되어 있고 "축소"는 선택할 수 있다. 최소 크기에서는 반대다.
4. **Given** 크기를 바꾼 뒤, **When** 앱을 다시 실행하면, **Then** 마지막 크기로 나타난다.
5. **Given** 캐릭터를 확대했을 때, **When** 커지거나 작아진 캐릭터 위를 클릭하면, **Then** 보이는 크기만큼의 영역이 클릭을 받고 그 밖은 아래 창으로 전달된다(001의 클릭 통과 유지).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 우클릭 메뉴는 "확대", "축소", "캐릭터 설정", "종료" 항목을 제공해야 한다.
- **FR-002**: "종료"는 앱을 완전히 종료해야 한다.
- **FR-003**: "확대"·"축소"는 캐릭터 크기를 한 단계(`config.scale.step`)씩 바꾸고, 최소(`config.scale.min`)와 최대(`config.scale.max`)를 넘지 않아야 한다.
- **FR-004**: 한계에 도달한 방향의 메뉴 항목은 메뉴를 열 때 비활성화되어야 한다.
- **FR-005**: 크기는 캐릭터 이미지, 위치, 방향, 이동 상태를 바꾸지 않고 표시 크기만 바꿔야 하며, 클릭을 받는 영역도 같은 비율로 바뀌어야 한다.
- **FR-006**: 크기는 앱을 다시 실행해도 유지되어야 한다. 저장된 값이 범위를 벗어나면 범위 안으로 맞춰야 하고, 숫자가 아니면 손상으로 보고 기본 크기로 시작해야 한다.
- **FR-007**: 기본 캐릭터와 등록한 모든 캐릭터에 같은 크기 설정이 적용되어야 한다(캐릭터를 바꿔도 크기는 유지).

### Key Entities

- **크기 배율**: 캐릭터 표시 크기의 배율. 기본 1이며 소수 둘째 자리로 반올림해 저장한다. 활성 캐릭터와 무관한 하나의 설정이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: "종료"를 선택하면 1초 안에 캐릭터와 모든 창이 사라지고 프로세스가 끝난다.
- **SC-002**: "확대" 또는 "축소"를 선택하면 1초 안에 크기가 바뀐다.
- **SC-003**: 확대·축소를 여러 번 반복해도 배율 오차가 쌓이지 않고 한 단계씩 정확히 변한다(예: 1.0에서 확대 7번이면 1.7).
- **SC-004**: 앱을 10회 다시 실행해도 마지막 크기가 매번 유지된다.

## Assumptions

- 수치는 써 보면서 정리하기로 했으므로 현재 값은 임시 기본값이다: 한 단계 0.1배(10%p), 최소 0.5배, 최대 3배. 바꾸려면 `src/shared/config.ts`의 `scale`만 고치면 된다.
- 메뉴 항목을 한 번 선택하면 메뉴가 닫히므로, 연속 확대는 우클릭을 반복한다(메뉴를 열어 둔 채 반복 확대는 이번 범위가 아니다).
- 확대·축소는 마우스 휠이나 단축키로는 하지 않는다. 메뉴 항목만 제공한다.
- 크기 변경 시 캐릭터 중심 위치는 그대로이므로, 화면 가장자리에서 확대하면 캐릭터 일부가 화면 밖에 걸칠 수 있다.
- 이번 검증은 macOS에서 수행한다. Windows는 후속이다.
