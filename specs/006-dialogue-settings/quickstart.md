# Quickstart: 대사 설정 화면 검증

## 자동 검증

```bash
npm test                                   # 검증 함수, 저장·복원·기본 편집본, 서비스 규칙
npx tsc -p tsconfig.node.json && npx tsc -p tsconfig.web.json
npm run test:e2e                           # 설정 창에서 편집·저장·오류·복원, 저장한 문장이 말풍선에 나옴
```

E2E는 `KAKARU_USER_DATA`로 격리한다.

## 수동 검증 (사람이 수행, `tests/manual/results.md`에 기록)

`npm run dev -- --open-settings` 후:

1. 등록한 캐릭터 목록 항목의 "대사 편집"을 눌러 세 분류가 보인다 (US1-1).
2. "평소"에 문장 몇 개를 쓰고 저장하면 안내가 보이고, 다른 캐릭터를 열었다 돌아와도 남아 있다 (US1-2).
3. 그 캐릭터를 선택해 기다리면(최대 40초) 입력한 문장이 혼잣말로 나온다. "잡혔을 때"에 쓴 문장은 캐릭터를 잡으면 바로 나온다 (US1-5, SC-002).
4. 문장을 지우고 저장하면 더 이상 나오지 않는다 (US1-3).
5. 61자 문장, 51번째 줄, 빈 줄을 넣어 보면 각각 줄 번호와 이유가 보이고 저장이 막히거나(61자·51개) 자동으로 정리된다(빈 줄) (US2).
6. 같은 문장을 두 줄 쓰고 저장하면 하나로 합쳐졌다는 안내가 보인다 (US2-4).
7. 변경 후 저장하지 않고 다른 캐릭터를 누르면 저장 / 버리기 / 계속 편집 막대가 나온다 (US1-4).
8. 기본 캐릭터와 "나"의 문장을 고친 뒤 "처음 문장으로 되돌리기"를 눌러 확인하면 원래 문장이 돌아온다. 취소하면 그대로다 (US3).
9. 등록 캐릭터는 "모두 비우기"가 보이고, 비우면 말하지 않는다 (US3-2).
10. 편집 중인 등록 캐릭터를 목록에서 삭제하면 패널에 안내가 나오고 저장할 수 없다 (edge).

macOS에서만 수행한다. Windows 열은 "후속".
