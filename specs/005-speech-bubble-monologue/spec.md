# Feature Specification: 말풍선과 혼잣말

**Feature Branch**: `005-speech-bubble-monologue`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "말풍선과 혼잣말. 캐릭터 머리 위에 말풍선을 띄우는 기능과, 캐릭터가 가끔 혼자 말하는 혼잣말 기능. 혼잣말은 정해진 대화셋에서 무작위로 고른 문장을 말풍선으로 보여 준다. 대화셋의 종류(분류)는 모든 캐릭터가 공통이고, 각 분류에 들어가는 문장 값은 캐릭터마다 따로 정의된다. 기본 캐릭터와 샘플 캐릭터에도 기본 문장이 있어야 한다. AI 연동은 이번 범위가 아니다(추후 대화 기능의 기반)."

이 기능은 말풍선(표시)과 혼잣말(내용 선택·발화 시점)의 두 부분으로 나뉜다. 말풍선은 이후 대화 기능이 그대로 재사용하는 기반이다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 캐릭터가 혼자 말한다 (Priority: P1)

캐릭터가 돌아다니다 가끔 머리 위에 말풍선을 띄워 짧은 문장을 말하고, 잠시 뒤 말풍선이 사라진다. 사용자가 아무것도 하지 않아도 일어난다.

**Why this priority**: 사용자가 처음 체감하는 "살아 있는 느낌"이며, 말풍선 표시와 문장 선택이 모두 이 흐름에 들어 있어 단독으로 가치가 완결된다.

**Independent Test**: 앱을 켜 두면 일정 시간 안에 캐릭터 머리 위에 말풍선이 나타나 문장을 보여 주고 사라진다.

**Acceptance Scenarios**:

1. **Given** 캐릭터가 걷거나 쉬고 있을 때, **When** 혼잣말 간격이 지나면, **Then** 캐릭터 머리 위에 말풍선이 나타나 문장 하나를 보여 준다.
2. **Given** 말풍선이 떠 있을 때, **When** 표시 시간이 지나면, **Then** 말풍선이 사라진다.
3. **Given** 말풍선이 떠 있는 채 캐릭터가 걸을 때, **When** 캐릭터가 움직이면, **Then** 말풍선은 캐릭터 머리 위를 따라 움직인다.
4. **Given** 캐릭터가 화면 위쪽 가장자리에 있을 때, **When** 말풍선이 나타나면, **Then** 말풍선은 화면 밖으로 잘리지 않고 보인다.
5. **Given** 같은 분류에 문장이 여러 개일 때, **When** 혼잣말이 여러 번 일어나면, **Then** 문장이 무작위로 선택되고 직전에 한 문장이 곧바로 반복되지 않는다.

---

### User Story 2 - 캐릭터마다 다른 말투를 가진다 (Priority: P2)

대화셋의 분류는 모든 캐릭터가 같지만, 각 분류에 들어가는 문장은 캐릭터마다 다르다. 캐릭터를 바꾸면 말투(문장)도 그 캐릭터의 것으로 바뀐다. 기본 캐릭터와 샘플 캐릭터("빨간 모자")는 처음부터 자기 문장을 가진다.

**Why this priority**: 캐릭터 개성을 만드는 부분이지만, 말풍선과 혼잣말이 먼저 동작해야 의미가 있다.

**Independent Test**: 기본 캐릭터와 "빨간 모자"를 번갈아 선택하면 서로 다른 문장이 나온다.

**Acceptance Scenarios**:

1. **Given** 기본 캐릭터가 활성일 때, **When** 혼잣말이 나오면, **Then** 기본 캐릭터에 정의된 문장 중에서만 나온다.
2. **Given** 캐릭터를 "빨간 모자"로 바꿨을 때, **When** 혼잣말이 나오면, **Then** "빨간 모자"에 정의된 문장 중에서만 나온다.
3. **Given** 어떤 캐릭터가 특정 분류의 문장을 하나도 정의하지 않았을 때, **When** 그 분류의 혼잣말 시점이 오면, **Then** 말풍선은 나타나지 않고 오류도 보이지 않는다.
4. **Given** 문장 정의가 손상되었을 때, **When** 앱이 실행되면, **Then** 혼잣말만 일어나지 않을 뿐 캐릭터의 이동·메뉴는 정상 동작한다.
5. **Given** 사용자가 직접 등록한 캐릭터가 문장을 하나도 정의하지 않았을 때, **When** 혼잣말 시점이 오면, **Then** 말풍선은 나타나지 않는다(기본 캐릭터의 문장으로 대신하지 않는다).
6. **Given** 문장 목록에 빈 문장(공백만 있는 것 포함)이 섞여 있을 때, **When** 무작위로 고르면, **Then** 빈 문장은 후보에서 제외되어 절대 말풍선으로 나오지 않는다.

---

### User Story 3 - 상황에 맞는 말을 한다 (Priority: P3)

대화셋은 분류별로 나뉘어 있어, 평소에는 "평소" 분류의 문장을, 사용자가 캐릭터를 잡았을 때는 "잡혔을 때" 분류를, 5초 넘게 잡혀 발버둥칠 때는 "오래 잡혔을 때" 분류를 쓴다.

**Why this priority**: 분류가 실제로 쓰이는 것을 보여 주는 확장이다. 평소 분류만으로도 US1·US2는 완결된다.

**Independent Test**: 캐릭터를 잡으면 "잡혔을 때" 문장이, 5초 넘게 잡고 있으면 "오래 잡혔을 때" 문장이 말풍선으로 나온다.

**Acceptance Scenarios**:

1. **Given** 캐릭터가 걷고 있을 때, **When** 사용자가 캐릭터를 잡으면, **Then** "잡혔을 때" 분류의 문장이 말풍선으로 나온다.
2. **Given** 캐릭터를 잡고 5초가 지났을 때, **When** 발버둥 모션이 시작되면, **Then** "오래 잡혔을 때" 분류의 문장이 말풍선으로 나온다.
3. **Given** 평소 혼잣말 말풍선이 떠 있을 때, **When** 사용자가 캐릭터를 잡으면, **Then** 기존 말풍선이 새 문장으로 교체된다(두 개가 겹치지 않는다).
4. **Given** 우클릭 메뉴가 열려 있을 때, **When** 혼잣말 시점이 오면, **Then** 말풍선은 나타나지 않는다.

---

### Edge Cases

- 말풍선이 떠 있는 동안 확대·축소가 일어나면 말풍선은 새 크기의 캐릭터 머리 위로 맞춰진다.
- 캐릭터가 다른 모니터로 옮겨지면 말풍선도 그 모니터에서 보인다.
- 문장이 길면 말풍선이 줄바꿈되고 최대 길이를 넘는 문장은 정의 단계에서 거부하거나 잘라 낸다.
- 캐릭터를 바꾸는 순간 떠 있던 말풍선은 사라지거나 새 캐릭터의 문장으로 바뀌지 않고 그대로 만료된다.
- 말풍선은 사용자의 클릭을 가로막지 않는다(말풍선 위 클릭은 아래 창으로 전달된다).
- 앱 시작 직후에는 곧바로 말하지 않고 첫 혼잣말 간격이 지난 뒤 시작한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 캐릭터 머리 위에 말풍선을 띄워 텍스트 한 문장을 보여 줄 수 있어야 한다. 말풍선은 이후 대화 기능이 같은 방식으로 재사용할 수 있는 공통 기능이어야 한다.
- **FR-002**: 말풍선은 정해진 표시 시간이 지나면 사라지고, 표시 중에는 캐릭터의 움직임과 크기 변화를 따라가야 한다.
- **FR-003**: 말풍선은 어떤 위치에서도 화면 밖으로 잘리지 않아야 하며, 클릭을 가로채지 않아야 한다(001의 클릭 통과 유지).
- **FR-004**: 한 시점에 말풍선은 최대 하나만 보여야 한다. 새 말풍선은 기존 말풍선을 교체한다.
- **FR-005**: 캐릭터는 사용자 입력 없이 일정하지 않은 간격으로 혼잣말을 해야 한다(간격은 무작위 범위 안에서 정한다).
- **FR-006**: 혼잣말 문장은 대화셋의 해당 분류에서 무작위로 고르며, 같은 분류의 직전 문장을 곧바로 반복하지 않아야 한다(문장이 둘 이상일 때).
- **FR-007**: 대화셋의 분류 목록은 모든 캐릭터가 같고, 각 분류의 문장 목록은 캐릭터마다 따로 정의되어야 한다. 처음 분류는 "평소", "잡혔을 때", "오래 잡혔을 때" 세 가지다.
- **FR-008**: 기본 캐릭터와 샘플 캐릭터("빨간 모자")는 모든 분류에 기본 문장을 가져야 하며, 앱을 다시 실행해도 유지되어야 한다.
- **FR-009**: 어떤 캐릭터의 분류에 문장이 없거나 문장 정의가 손상되었으면 그 분류의 말풍선만 생략하고 다른 동작에는 영향을 주지 않아야 한다.
- **FR-010**: 캐릭터를 잡으면 "잡혔을 때", 잡은 지 5초가 지나 발버둥이 시작되면 "오래 잡혔을 때" 문장을 말풍선으로 보여 주어야 한다.
- **FR-011**: 우클릭 메뉴가 열려 있는 동안에는 혼잣말을 하지 않아야 한다.
- **FR-012**: 활성 캐릭터가 바뀌면 이후의 혼잣말은 새 캐릭터의 문장에서 골라야 한다.
- **FR-013**: 문장은 비워 둘 수 있어야 한다. 분류 전체가 비어 있거나 문장이 빈 값(공백만 포함)이면 무작위 후보에서 제외하고, 후보가 하나도 없으면 말풍선을 보여 주지 않아야 한다. 다른 캐릭터의 문장으로 대신하지 않는다.
- **FR-014**: 사용자가 등록한 캐릭터는 처음에는 문장이 모두 비어 있다. 이 캐릭터의 문장 편집 수단은 이번 범위가 아니다.

### Key Entities

- **대화셋 분류**: 문장 묶음의 종류. 모든 캐릭터가 같은 목록을 쓴다(평소, 잡혔을 때, 오래 잡혔을 때).
- **문장 목록**: 한 캐릭터가 한 분류에 가진 문장들. 캐릭터마다 다르며 비어 있을 수 있다.
- **말풍선**: 한 시점에 하나만 존재하는, 한 문장을 일정 시간 보여 주는 표시. 출처(혼잣말, 이후 대화)와 무관하게 같은 방식으로 표시된다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 앱을 켠 뒤 1분 안에 최소 한 번 혼잣말 말풍선이 나타난다.
- **SC-002**: 말풍선은 문장을 다 읽을 수 있을 만큼 보였다가(문장 길이에 비례해 최소 3초) 사라진다.
- **SC-003**: 말풍선이 떠 있는 동안 캐릭터가 걷거나 확대·축소되어도 말풍선이 캐릭터 머리에서 떨어져 보이지 않는다.
- **SC-004**: 화면의 네 가장자리 어디에서 말풍선이 나와도 글자가 잘리지 않는다.
- **SC-005**: 말풍선이 떠 있을 때도 말풍선 영역 아래의 다른 앱을 평소처럼 클릭할 수 있다.
- **SC-006**: 두 캐릭터를 번갈아 선택하면 각각 자기 문장만 나온다(다른 캐릭터의 문장이 섞이지 않는다).
- **SC-007**: 혼잣말 기능을 추가한 뒤에도 유휴 CPU 평균이 기준(10% 이하)을 넘지 않는다.
- **SC-008**: 기존 이동·드래그·우클릭 메뉴·확대·축소 검증이 모두 그대로 통과한다.

## Assumptions

- 혼잣말 간격은 20~40초 사이의 무작위 값, 말풍선 표시 시간은 문장 길이에 비례하되 최소 3초·최대 8초로 한다(직접 써 보고 조정).
- 분류의 처음 세 가지(평소, 잡혔을 때, 오래 잡혔을 때)는 기존 상호작용에서 바로 쓸 수 있는 것만 골랐다. 새 분류를 늘리는 것은 후속이다.
- 사용자 등록 캐릭터는 문장이 비어 있어 말하지 않는다. 문장을 채우는 방법(설정 창 편집 등)은 후속이며, 저장 형식은 캐릭터마다 분류별 문장 목록을 담을 수 있게 계획 단계에서 정한다.
- 문장은 텍스트만 지원한다(이모지는 표시되면 그대로 보이지만 별도 처리하지 않는다). 이미지·서식·효과음은 범위 밖이다.
- 말풍선의 모양은 단순한 둥근 사각형과 꼬리로 하며, 캐릭터별 말풍선 디자인은 범위 밖이다.
- AI 연동, 사용자 입력에 대한 응답, 대화 기록은 범위 밖이다. 말풍선은 이후 대화 기능이 재사용하도록 출처와 무관하게 만든다.
- 이번 검증은 macOS에서 수행한다. Windows는 후속이다.
