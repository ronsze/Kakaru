# 수동 검증 결과

`specs/001-character-autonomous-movement/quickstart.md`의 절차에 따른 검증 기록이다.
자동화할 수 없는 항목(실제 화면 관찰, 다른 앱 클릭, 멀티 모니터, 전체 화면 앱)은 사람이 직접
확인해야 하며, 아래 "미수행" 항목은 아직 확인하지 않았다.

## 자동 검증 (2026-10-22, macOS)

| 항목 | 결과 |
|---|---|
| 단위 테스트 (`npm test`) | 36개 통과 (area, behavior, behavior-user-control, hit) |

| 타입 검사 (`tsc`, node/web) | 통과 |

## 성능 측정 (T037, macOS, 단일 디스플레이, 유휴 20초 후 6초 간격 2회차 샘플)

| 시점 | CPU 합계 | 메모리 합계 | 비고 |
|---|---|---|---|
| 최초 구현(전체 캔버스 매 프레임 지움, 60fps) | 약 25% | 약 280MB | GPU 프로세스와 렌더러가 대부분 |
| 변경 후(변경 영역만 지움, 32fps 제한, 비가시 창은 프레임 중단) | 약 14% | 약 220MB | main 3.8%, GPU 5.4%, 렌더러 4.8% |

- **SC-006 (CPU 3% 이하)는 미달**이다. 메모리(300MB 이하)와 SC-007(30fps 이상)은 충족한다.
- 원인은 전체 화면 크기의 투명 창을 합성하는 비용이다. 추가 최적화로 줄일 수는 있으나
  Electron 투명 오버레이의 특성상 3%는 현실적이지 않을 수 있다. 목표 조정 여부는 결정이 필요하다.
- Windows는 측정하지 않았다.
