# Feature Specification: 실행할 때 인사

**Feature Branch**: `007-startup-greeting`

**Created**: 2026-10-22

**Status**: 구현 완료, macOS 수동 검증 대기

**Input**: User description: "처음 실행하면 인사하도록"

아주 작은 변경이라 plan·tasks 없이 바로 구현했다(003 선례). 005의 대화셋에 "인사" 분류를 하나 더하고, 앱을 실행하면 활성 캐릭터가 그 분류의 문장으로 인사한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 앱을 켜면 캐릭터가 인사한다 (Priority: P1)

사용자가 앱을 실행하면 캐릭터가 나타나고 잠시 뒤 말풍선으로 인사한다. 인사 문장은 캐릭터마다 다르고 설정 창에서 편집할 수 있다.

**Independent Test**: 앱을 실행하면 약 2초 안에 활성 캐릭터가 인사 분류의 문장을 말풍선으로 말한다.

**Acceptance Scenarios**:

1. **Given** 앱을 실행했을 때, **When** 오버레이가 뜨고 약 1.5초가 지나면, **Then** 활성 캐릭터가 "인사" 분류의 문장 하나를 말풍선으로 말한다.
2. **Given** 활성 캐릭터의 "인사" 분류에 문장이 없을 때(직접 등록한 캐릭터 등), **When** 앱을 실행하면, **Then** 인사하지 않고 오류도 없다.
3. **Given** 인사 직전에 우클릭 메뉴가 열려 있거나 캐릭터를 잡고 있을 때, **When** 인사 시점이 되면, **Then** 그 인사는 건너뛴다(다시 하지 않는다).
4. **Given** 앱을 실행한 뒤, **When** 시간이 흐르면, **Then** 인사는 실행당 한 번만 하고 이후는 평소 혼잣말이 이어진다.

### User Story 2 - 인사 문장을 편집한다 (Priority: P2)

대사 설정 화면에 "인사 (실행할 때)" 분류가 생기고, 다른 분류와 같은 규칙(1~60자, 분류당 50개)으로 편집한다.

**Independent Test**: 설정 창에서 인사 문장을 바꿔 저장하고 앱을 다시 실행하면 바뀐 문장으로 인사한다.

## Requirements *(mandatory)*

- **FR-001**: 대화셋 분류는 인사, 평소, 잡혔을 때, 오래 잡혔을 때 네 가지이며 모든 캐릭터가 공통이다.
- **FR-002**: 앱을 실행한 뒤 `config.greetingDelayMs`(1.5초) 후 한 번, 활성 캐릭터가 "인사" 분류에서 무작위로 고른 문장을 말한다.
- **FR-003**: 인사 시점에 메뉴가 열려 있거나 잡혀 있으면 인사하지 않는다. 문장이 없으면 인사하지 않는다.
- **FR-004**: 기본 캐릭터와 샘플 캐릭터("빨간 모자", "나")는 인사 문장을 가진다. 등록한 캐릭터는 비어 있으며 설정 창에서 채울 수 있다.
- **FR-005**: 인사 분류가 생기기 전에 저장된 데이터는 보존한다. 기본 캐릭터의 편집본에 인사 항목이 없으면 내장 인사를 쓰고, 이미 설치된 샘플의 `lines.json`에 인사 항목이 없으면 시작할 때 샘플 원본의 인사만 채운다(사용자가 고친 다른 문장은 그대로다).
- **FR-006**: 인사 분류는 대사 설정 화면에서 다른 분류와 같은 방식으로 편집·검증·되돌리기가 된다.

## Success Criteria *(mandatory)*

- **SC-001**: 앱을 실행하고 3초 안에 인사 말풍선이 보인다(인사 문장이 있는 캐릭터).
- **SC-002**: 인사 문장이 없는 캐릭터는 실행해도 말풍선이 나오지 않는다.
- **SC-003**: 기존 혼잣말·잡았을 때 대사·대사 설정 화면 검증이 그대로 통과한다.

## Assumptions

- "처음 실행하면"은 앱을 실행할 때마다로 해석했다. 설치 후 처음 한 번만 하는 방식(첫 실행 안내)은 범위 밖이다. 필요하면 후속으로 `settings.json`에 첫 실행 기록을 더한다.
- 인사는 실행당 한 번이다. 모니터 변경·절전 복귀로는 다시 하지 않는다.
- 이번 검증은 macOS에서 수행한다. Windows는 후속이다.
