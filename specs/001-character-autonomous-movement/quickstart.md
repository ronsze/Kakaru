# 퀵스타트: 캐릭터 자율 이동 검증

기능이 끝까지 동작하는지 확인하는 절차다. 구현 코드는 포함하지 않는다. 구조는
[plan.md](./plan.md), 상태 모델은 [data-model.md](./data-model.md), IPC는
[contracts/ipc.md](./contracts/ipc.md)를 따른다.

## 사전 준비

- Node.js LTS, npm
- macOS와 Windows 각 1대 이상(멀티 모니터 검증 시 외부 모니터)

## 실행

```bash
npm install
npm run dev        # 개발 실행
npm test           # 단위 테스트 (Vitest)
npm run test:e2e   # Electron E2E (Playwright)
```

## 자동 검증 (기대 결과)

- 이동 로직 단위 테스트가 모두 통과한다: 상태 전이, 경계 반사, 목표 선택, 영역 합집합 판정.
- E2E: 앱 기동 후 5초 안에 `character:update`의 위치가 변한다(SC-001).

## 수동 검증 (mac, Windows 각각)

| # | 절차 | 기대 결과 | 관련 |
|---|---|---|---|
| 1 | 앱 실행 후 입력 없이 1분 관찰 | 캐릭터가 5초 안에 움직이기 시작하고, 이동·정지·방향 전환을 반복한다 | US1, SC-001 |
| 2 | 10분간 방치 | 화면 밖으로 나가지 않고 한 지점에 영구히 멈추지 않는다 | SC-002, FR-004 |
| 3 | 캐릭터가 이동 중인 위치 근처의 다른 앱 버튼·링크를 클릭 | 캐릭터가 없는 영역의 클릭은 아래 앱에 정상 전달된다 | US2, FR-005, SC-003 |
| 4 | 다른 앱에서 타이핑하는 동안 캐릭터 이동 | 포커스·입력이 유지된다 | US2 |
| 5 | 캐릭터 위를 클릭 | 클릭이 아래 앱이 아닌 캐릭터 창으로 들어간다(통과 해제) | R2 |
| 6 | (멀티 모니터) 모니터 사이로 이동, 모니터 연결·해제 | 모니터 간 이동이 되고, 해제 시 남은 화면으로 복귀한다 | FR-008 |
| 7 | 전체 화면 앱(영상·브라우저 F11) 실행 | 입력을 가로채지 않는다. 표시 여부는 R3 한계에 따른다 | 엣지 케이스 |
| 8 | 절전 후 복귀 | 이동이 정상 재개된다 | 엣지 케이스 |

사용자 조작(롱프레스·우클릭 메뉴)과의 공존(US3, SC-004)은 해당 기능이 구현될 때 같은
절차에 추가해 검증한다. 이번 기능에서는 `UserControlled` 상태 전이를 단위 테스트로 확인한다.
