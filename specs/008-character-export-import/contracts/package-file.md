# 계약: .kakaru 파일 형식

## 형식

UTF-8 JSON 한 파일. 확장자 `.kakaru`. 줄바꿈·들여쓰기는 자유(내보낼 때는 2칸 들여쓰기).

```json
{
  "format": "kakaru-character",
  "version": 1,
  "name": "나",
  "frames": 8,
  "walk": "iVBORw0KGgo…(base64 PNG)",
  "idle": "iVBORw0KGgo…(base64 PNG)",
  "lines": {
    "greeting": ["븜하~"],
    "normal": ["븜븜븜~ 아주 작은 븜동차"],
    "grabbed": ["븜?"],
    "struggling": ["놓으라븜"]
  }
}
```

## 규칙

- 내보낼 때 네 분류를 모두 쓴다(빈 목록 포함). 가져올 때는 없는 분류를 빈 목록으로 본다.
- `walk`·`idle`은 표준 base64(패딩 허용, 줄바꿈·공백 없음)다. 가져올 때 문자 집합을 먼저 확인한 뒤 디코딩한다.
- 디코딩한 이미지는 기존 이미지 등록 규격을 그대로 따른다(`validateRegistration`): PNG, 5MB 이하, 알파 채널과 투명 픽셀, 걷기 `너비 = 높이 × frames`·높이 64~512, 정지는 정사각형이며 한 변이 걷기 높이와 같음.
- 대사는 기존 규칙을 따른다(`validateLinesInput`): 문장당 60자 이하, 분류당 50개 이하.
- 이식 정보만 담는다. 경로, 사용자 이름, 시각, id, 활성 여부는 쓰지 않는다.
- 판별은 내용(`format`)으로 한다. 확장자는 보지 않는다.

## 버전 정책

- `version`이 1보다 큰 파일은 거부한다("지원하지 않는 버전").
- 필드를 더하는 호환 변경은 버전을 올리지 않고(알 수 없는 키 무시), 의미가 바뀌는 변경만 올린다.
- 이 버전(1)에서 정의한 필드의 의미는 바꾸지 않는다.

## 크기

파일 16MB 이하. 열기 전에 크기를 확인한다.
