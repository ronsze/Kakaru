# Data Model: 말풍선과 혼잣말

## 분류 (공통)

`normal`(평소), `grabbed`(잡혔을 때), `struggling`(오래 잡혔을 때). 코드 상수이며 캐릭터가 늘리거나 줄일 수 없다.

## Lines (캐릭터별)

`Record<분류, string[]>`. 모든 분류 키가 항상 존재하고 비어 있을 수 있다.

| 규칙 | 값 |
|---|---|
| 문장 | 문자열, 앞뒤 공백 제거 후 1~60자. 빈 값·공백만·60자 초과·문자열이 아닌 값은 제외 |
| 분류당 문장 수 | 최대 50개(넘으면 앞에서 50개) |
| 알 수 없는 분류 키 | 무시 |
| 파일 없음·파싱 실패·형식 오류 | 모든 분류가 빈 목록 |

저장 위치와 형식: [contracts/lines-file.md](./contracts/lines-file.md). 기본 캐릭터는 코드 상수.

## Speech (메모리, 저장하지 않음)

| 필드 | 설명 |
|---|---|
| `id` | 발화마다 증가하는 번호. 렌더러가 새 발화인지 판별 |
| `text` | 말풍선 문장 |
| `until` | 사라질 시뮬레이션 시각(ms) |

한 시점에 최대 하나. 새 발화가 이전 것을 교체한다.

## Speaker 상태

- `nextMonologueAt`: 다음 평소 혼잣말 시각(간격 범위의 무작위)
- `last[분류]`: 분류별 직전 문장
- `current`: 현재 Speech 또는 null
- 전이: `update`가 시각 도달 시 `normal`에서 선택해 `current`를 설정하고 다음 시각을 다시 잡는다. 메뉴가 열려 있거나 잡는 중이면 발화하지 않고 다음 시각만 다시 잡는다. 후보가 없으면 `current`를 바꾸지 않는다.
