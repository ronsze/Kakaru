# 데이터 모델: 우클릭 메뉴와 캐릭터 리소스 설정

## CharacterSet (캐릭터 세트)

등록된 캐릭터 하나. 기본 캐릭터는 코드에 내장된 읽기 전용 세트이며 저장소에는 기록하지 않는다.

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | `string` | 등록 시 생성하는 식별자. 정규식 `^[a-z0-9]{8,32}$`. 폴더 이름으로 쓰인다 |
| `name` | `string` | 앞뒤 공백 제거 후 1~30자 |
| `frames` | `number` | 걷기 프레임 수, 정수 2~32 |
| `frameSize` | `number` | 프레임 한 변의 픽셀 수 `S`, 64~512 |
| `createdAt` | `number` | 등록 시각(ms, epoch) |

### 검증 규칙

- `name`은 "앞뒤 공백 제거 후 1~30자"이며 다른 세트의 이름과 대소문자 구분 없이 같으면 안 된다.
  예약어 "기본"은 쓸 수 없다.
- `frames`는 "정수 2~32", `frameSize`는 "64~512".
- 걷기 이미지의 크기는 "너비 = `frameSize` × `frames`, 높이 = `frameSize`", 정지 이미지는 "너비 =
  높이 = `frameSize`"이다. 두 이미지 모두 알파 값이 255가 아닌 픽셀이 하나 이상 있어야 한다.
- 이미지는 PNG이고 각각 5MB 이하다.

## Settings (저장소 상태)

| 필드 | 타입 | 설명 |
|---|---|---|
| `version` | `1` | 파일 형식 버전 |
| `activeId` | `string \| null` | 활성 캐릭터 id. `null`이면 기본 캐릭터 |
| `characters` | `CharacterSet[]` | 등록된 캐릭터. 등록 순서대로 |

### 불변식

- `activeId`가 `null`이 아니면 `characters`에 그 id가 있어야 하고 이미지 파일이 읽혀야 한다. 어긋나면
  `activeId`를 `null`로 되돌리고 `problem`을 설정한다(FR-015).
- 캐릭터를 삭제할 때 `activeId`와 같으면 `activeId`를 `null`로 바꾼다(FR-013).
- 모든 쓰기는 임시 파일에 쓴 뒤 이름을 바꿔 원자적으로 반영한다.

## Appearance (오버레이에 적용되는 모습)

저장하지 않는 파생 값. 활성 캐릭터에서 만든다.

| 필드 | 타입 | 설명 |
|---|---|---|
| `walkUrl` | `string \| null` | 걷기 이미지의 `data:` URL. `null`이면 기본 이미지 |
| `idleUrl` | `string \| null` | 정지 이미지의 `data:` URL. `null`이면 기본 이미지 |
| `frames` | `number` | 걷기 프레임 수(기본 캐릭터는 8) |

## MenuState (메뉴 상태)

메모리 상태. 메뉴가 열려 있는지 하나만 기록한다.

```text
          우클릭(캐릭터 위)
 Closed ───────────────────► Open ── 캐릭터 이동 정지(UserControlled)
   ▲                           │
   └── 메뉴 닫힘(밖 클릭·Esc·항목 선택) ┘  → 현재 위치에서 Idle로 재개
```

- `Open`일 때 들어온 우클릭은 무시한다(중복 열림 방지, FR-005).
- 항목을 선택해 설정 창을 여는 경우에도 메뉴는 닫힘 처리되고 캐릭터는 재개된다.

## ProblemNotice (문제 알림)

- 활성 캐릭터를 읽을 수 없어 기본으로 되돌린 경우 설정 화면에 표시할 메시지. 메모리에만 두며 다음
  목록 조회 때 사용자가 확인하면 지운다.
